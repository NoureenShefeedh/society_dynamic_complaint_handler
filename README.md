# Society Maintenance Tracker

A complaint management platform for apartment societies. Residents raise and
track complaints with photos; admins manage them through a status workflow
with priority scoring, overdue detection, and a notice board.

## Status
🚧 In development. This README will be filled in with full setup instructions,
API docs, and the database schema as the project progresses.

## Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js + Express
- **Database:** PostgreSQL (Supabase)
- **File storage:** Supabase Storage
- **Email:** Nodemailer (Gmail SMTP) / Resend
